# ai-server-test

이 폴더는 AI 서버 관련 기능 검증 문서와 증빙을 보관한다.

## 구성

- `testing.md` - 로컬/배포 검증 절차
- `ai-api.md` - AI 분류 API 설명
- `task6-manifest-snapshot/` - 매니페스트 스냅샷 검증 증빙
- `task7-policy-falco-hygiene/` - 정책/Falco 하이진 검증 증빙

## 역할

- 테스트 방법과 결과를 남겨서 나중에 같은 흐름을 다시 재현할 수 있게 한다.
- 구현 코드 대신 캡처 이미지와 문서 중심으로 정리한다.
