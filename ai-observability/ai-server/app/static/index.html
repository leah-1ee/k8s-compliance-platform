Kubernetes 정책 생성부터 런타임 위반 분석까지 한 화면에서 운영하는 Policy-as-Code 콘솔입니다.

Google로 시작 개발 로그인

Google 로그인은 운영 환경용이며, 개발 로그인은 로컬/데모 모드에서만 사용합니다.

현재 로그인 공급자가 설정되지 않았습니다. 공개 Policy Generator는 계속 사용할 수 있습니다.

01 Natural language to Gatekeeper

요구사항을 입력하면 ConstraintTemplate, Constraint, Rego 산출물을 생성합니다.

02 Falco Sidekick ingest

사용자 클러스터를 등록하고 런타임 이벤트를 안전하게 수집합니다.

Falco 이벤트가 수집되면 런타임 위반 목록과 상세 분석 흐름에서 확인할 수 있습니다.

03 AI-assisted triage

위반 원인, 심각도, 수정 방향을 사용자 클러스터 범위 안에서 분석합니다.

Policy

정책을 빠르게 표준화

latest 태그 금지, non-root 강제, 허용 레지스트리 같은 Kubernetes 보안 규칙을 생성합니다.

Runtime

클러스터별 이벤트 관측

Falco와 Gatekeeper 신호를 클러스터, 소스, 심각도 기준으로 확인합니다.

Report
