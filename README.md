# k8s-compliance-platform

Policy-as-Code 기반 Kubernetes 컴플라이언스 자동화 플랫폼  
OPA/Gatekeeper + Falco + AI 기반 통합 보안 플랫폼

## 팀원
- 성은 — 정책 엔진 (Gatekeeper)
- 은성 — 런타임 탐지 (Falco)
- 온 — AI + 대시보드

## 기술 스택
- OPA/Gatekeeper
- Falco + Falco Sidekick
- Prometheus + Grafana
- FastAPI + LLM API
